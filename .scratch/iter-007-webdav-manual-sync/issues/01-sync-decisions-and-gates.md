# 01：定案同步 ADR 与验收规则

Status: resolved

ITER: ITER-007

**What to build:** 更新 ADR 0001，把本轮已确认的本机找回、原始成员同步和安全启用决策记为正式产品承诺，取代原来的逐字段裁决承诺。此票只定案，不改变运行行为。

**Blocked by:** 无，可立即开始。

- [x] ADR 区分两类找回：旧表单只保存未冲突字段，过时草稿留本机；同步合并或删除覆盖本机手写值时，不论是否已发布都留本机。
- [x] ADR 明确同 URL 只合并展示，按原始 ID 保留独立成员与字段修订；删除只覆盖确认开始时可见的成员，新 ID 可以重新收藏。
- [x] 明确前置顺序：找回入口和存量候选访问先于旧裁决移除，乱序收敛测试先于快照格式冻结，双配置回归与目标 WebDAV 实测先于启用。
- [x] 将晚到写拆成两种证据：已见新代次的对端可以拒绝倒退；首次加入端没有该本机记录，不能凭一次发端回读判定目标服务安全。
- [x] 术语表对齐确定性合并与本机找回；路线图区分现有全量备份与尚未启用的手动双向同步，并从 ITER-007 链接首期规格。

# 14：纯接收不重复上传，补齐新收藏默认字段

Status: ready-for-agent

ITER: ITER-007

**What to build:** 用户手动拉取收藏变更后，不因另一端已经发布的相同状态再次上传快照；新接收的收藏具备正常显示和分类所需的本机默认值。

**Blocked by:** 无。

- [ ] 双配置验证：合并后远端有效发布中已有校验通过的同状态快照，且本机没有待确认发布，则纯接收不写远端。合并产生远端尚未发布的新状态时仍正常发布，待确认发布保留原恢复和核验流程。
- [ ] 已加入但从未发布的配置，无变化时仍校验目录和选中发布记录，不再下载或上传快照。只复用已经验证过的状态；新发现的快照仍校验身份和摘要。真实 `404` 最多重新发现一次，损坏或不完整清单仍安全暂停，不能被短路掩盖。
- [ ] 远端新增收藏在本机具备从 URL 得出的来源、未读状态和未归项目的默认值；同步不重置已有收藏的本机关联。验证用户能看到新增项，并核对实际远端请求。

# 04：创建同步收藏库并发布首份快照

Status: ready-for-agent

ITER: ITER-007

**What to build:** 在仅供隔离验收的设置入口，用户明确创建同步收藏库并发布首份可验证的同步快照。看不到库或无法确认索引都不算成功，不把此入口开放给未验收的真实服务。

**Blocked by:** [01：定案同步 ADR 与验收规则](01-sync-decisions-and-gates.md)、[03：修正 WebDAV 传输与流量计量](03-webdav-transport-and-metering.md)。

- [ ] **先测试、后冻结格式。** 在实际纯合并与哈希入口重排 A、B 同 URL 独立新增与仅删除 A 的输入，并重放旧快照；各排列完整状态、B 的字段及修订和 `stateHash` 一致，且保留 A 的删除记录。源状态不物理折叠成员。
- [ ] `stateHash` 基于规范化同步状态，包含成员、修订与删除记录；不受发布代次、传输时间、展示投影、本机找回记录或无语义的集合排列影响。
- [ ] 通过设置真实创建：生成新的库身份及绑定代次，设备标识属于浏览器配置且重启不变，同步元数据独立存储；连接错误、不可读或不完整发现不得视为空目录并写入。
- [ ] 通过设置手动触发：在隔离目录先写本设备不可变 gzip 快照，再写本设备索引并回读；仅确认与意图相符的发布。验证设备索引确实指向可读、身份与摘要正确的快照，不使用 ETag 条件写，不产生后台轮询。
- [ ] 在首次发出写入前持久化已分配代次和轻量待确认记录：库及设备身份、代次、快照引用和摘要、索引载荷、本机版本。不把完整快照本体长期写入本机存储，也不因重启或同设备重绑同库复用已发出的代次。中断后的恢复行为由 `08` 验收。

# 12：同步项目级联删除，暂停已读自动清理

Status: ready-for-agent

ITER: ITER-007

**What to build:** 让用户主动删项目时随之删除的收藏能同步到另一端；绑定同步收藏库期间，不让本机已读清理擅自删除收藏。不扩大首期同步范围。

**Blocked by:** 无。

- [ ] 从项目删除入口删除项目时，本机删除及其删除记录同批提交。下一次手动同步后，另一端移除的是实际被删的原始收藏，不同步项目或归属，不误删同 URL 的其他成员；重放旧快照不复活已删成员。
- [ ] 同步收藏库绑定期间，即使原设置开启，定时或设置变化触发的已读自动清理也不删除过期收藏或产生删除记录。解绑后按原开关和保留期限恢复，不改用户偏好。
- [ ] 双配置验证项目级联删除的实际同步结果；从真实后台清理入口验证绑定和解绑前后的存储结果。

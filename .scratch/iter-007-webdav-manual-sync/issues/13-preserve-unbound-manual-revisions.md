# 13：保留未绑定期间的手写修订

Status: ready-for-agent

ITER: ITER-007

**What to build:** 用户在未绑定或解绑后亲手修改的标题和摘要，在首次接入或重绑时按实际编辑产生的字段修订参与合并，不在接入时给旧值制造新修订。

**Blocked by:** 无。

- [ ] 从真实编辑入口提交手写标题、摘要或显式清空摘要时，只为实际修改且成功提交的字段记录本机修订；修订跨重启保留。自动补全、同步接收及未修改字段不冒充本机的新手写修订。
- [ ] 创建或加入同步收藏库时使用已有的本机手写修订，不用接入时间替代编辑时间。旧数据缺乏修订证据时不凭内容不同或手写标记提权，按现有合并与本机找回规则处理。
- [ ] 用双配置分别验证：较新的本机手改在重绑后不会输给较旧的远端值；没动过的本机旧值不会盖过远端较新的编辑。检查独立字段和被自动覆盖的本机手写值仍能按原规则找回。

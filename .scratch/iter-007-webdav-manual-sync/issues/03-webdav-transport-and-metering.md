# 03：修正 WebDAV 传输与流量计量

Status: resolved

ITER: ITER-007

**What to build:** 用户通过现有设置页备份时，传输类型正确，重试不会将每个未知结果都显示成一次完整扣减；后续同步复用同一预算口径而不更改备份格式。

**Blocked by:** 无，可立即开始。

- [x] 真实传输链路按请求内容设置媒体类型：现有备份仍发送 ZIP，共用接口也能分别传 JSON 设备索引和 gzip 快照；不能沿用硬编码的 ZIP 类型。
- [x] 验证成功、明确失败、响应超时但服务端可能已收全及重试；账目区分已确认与不确定传输，不把未知报成零消耗，也不在每次发起时把同一逻辑操作全量记为已确认。
- [x] 按请求侧记录和本机预算结果断言实际行为；现有设置页备份、列表或下载恢复路径仍可独立使用，不修改 ZIP 格式。

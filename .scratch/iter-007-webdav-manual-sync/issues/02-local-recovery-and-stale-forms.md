# 02：本机找回与旧表单保护

Status: ready-for-agent

ITER: ITER-007

**What to build:** 用户从真实收藏编辑框提交旧表单时，仍有效的改动照常保存，过时草稿不会盖掉当前值；设置页能找回这些草稿及存量旧候选，为后续撤掉卡片裁决提供替代入口。

**Blocked by:** [01：定案同步 ADR 与验收规则](01-sync-decisions-and-gates.md)。

- [ ] 编辑框打开后同一字段被后台更新，再修改两个字段并提交：冲突字段保留当前值、草稿有轻提示且可找回，另一个字段正常保存，未编辑字段不写回。
- [ ] 找回记录区分旧表单草稿与被自动覆盖的本机手写值，独立本机、持久且有界；设置页支持查看、复制和清理，清理不改收藏，不自动复活历史 ID。
- [ ] 草稿留档与本次收藏提交在共享写队列内同批完成；关闭页面或重启后能找回，不污染收藏或全量备份格式。
- [ ] 验证存量待裁决内容在新入口可找回；本票不移除旧入口。测试用真实编辑与存储流程，不用模拟裁决结果代替断言。

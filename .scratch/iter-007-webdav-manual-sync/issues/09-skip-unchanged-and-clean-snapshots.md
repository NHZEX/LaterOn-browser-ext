# 09：无变化短路与旧快照清理

Status: ready-for-agent

ITER: ITER-007

**What to build:** 已收敛的浏览器配置再次手动同步时不重复传输快照。旧快照可尽力清理，同时读取旧设备索引的对端仍有机会追到新快照。

**Blocked by:** [08：发布中断、重启与晚到写保护](08-resume-and-reject-late-head.md)。

- [ ] 在发现已完成、没有待确认发布或待重试清理的稳态下，用两配置真实链路和服务端请求记录证明只读设备索引：零下载快照、零上传快照、零重写索引。存在待确认发布时不能误走短路。
- [ ] 清理只在回读确认新索引后按本机记录处理本设备的快照，当前及上一代是尽力保留的目标；不为清理列目录，不删除其他设备快照或删除记录。清理失败保留待重试，不误报已确认发布失败。
- [ ] 对端读取旧索引指向的快照遇到 `404` 时，限次重读索引并校验新的引用；仍无法确认时明确报错或暂停，不以空状态合并。发现阶段碰到 `PROPFIND` 限额或不完整返回不据此判空、判设备消失。

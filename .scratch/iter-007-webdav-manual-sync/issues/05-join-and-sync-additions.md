# 05：加入已有库并手动同步新增收藏

Status: resolved

ITER: ITER-007

**What to build:** 第二套浏览器配置可以核对并加入同一个同步收藏库，两端主动同步新增的收藏；取消、解除绑定或操作本机恢复，都不会误修改其他设备的数据。

**Blocked by:** [04：创建同步收藏库并发布首份快照](04-create-sync-library.md)。

- [x] 设置页区分创建与加入，加入核对已知库身份并预览；取消不改两端收藏、不发布；非空本机确认后、落盘前先保留可用的本机恢复副本。错误身份、坏快照或目录发现不完整不能落盘或当成空库继续。
- [x] 两个隔离 Chromium 配置通过真实设置和收藏入口互相同步新增，包括离线新增、恢复连接后手动同步。按原始 ID 保留成员；同 URL 在收藏库和侧边栏只展示一张卡片，展示 ID 确定，本机私有字段与本机关联不被重置。
- [x] 本机 B 已有手动封面、续读位置和当前列表排序槽位，收到更早的同 URL 成员 A 后，卡片成为 A，仍能使用 B 的本机关联。优先使用规范成员已有的同类关联，缺失时按确定性成员顺序回退；手动封面优先于自动封面。续读和关联更新读写同一个存活成员，排序只查当前范围，不移动存储键；验证位置 `0` 不被当作缺失。
- [x] 延迟旧下载和待发送的旧写操作，解除绑定后重新加入相同 `collectionId`，确认新 `bindingId` 已生效。入站在写队列内复核、重读最新本机状态后提交；旧回包不落盘，尚未发出的旧写不产生服务端请求。
- [x] 清空收藏或从全量备份覆盖恢复先解除绑定，不把此次操作传播给另一端；已发出的请求不承诺撤回，留给晚到写门禁验收。同步运行与结果可在设置页观察，仍仅供隔离验证。

验证入口见 [浏览器测试说明](../../../tests/browser/README.md#首份-webdav-同步快照)。

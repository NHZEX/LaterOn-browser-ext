# 06：双向编辑标题与摘要，替换旧裁决

Status: ready-for-agent

ITER: ITER-007

**What to build:** 用户在两端编辑标题或摘要时可以直接手动同步，系统自动收敛；旧表单草稿及败选手写值仍能通过设置找回，不再需要逐字段卡片裁决。

**Blocked by:** [02：本机找回与旧表单保护](02-local-recovery-and-stale-forms.md)、[05：加入已有库并手动同步新增收藏](05-join-and-sync-additions.md)。

- [ ] 两配置通过真实界面并发改不同字段时，两项编辑均保留；改同一字段时按字段修订确定性收敛，重启和旧快照重放不改变结果；显式清空摘要能同步，远端值不冒充本机手写值。
- [ ] 编辑同 URL 合并卡片时，按打开编辑框所见的来源成员及修订作为基线，只将改动写回仍有效的字段。来源变更或消失、或字段已更新时保留当前值，被拒绝的草稿可找回；同次其他有效字段照常保存。
- [ ] 自动合并覆盖手写值时，已发布和未发布的本机值均在找回入口可查；记录随合并提交，不因同一输入重放重复，不同步到对端。
- [ ] 重复收藏的自动标题/摘要补全不产生已有成员的新同步修订。两配置分别进行离线自动刷新与手动编辑，重连后手写值仍可见，自动值不入找回记录；从对端收到的手写值不能仅因手写标记而算作本机用户写入。
- [ ] 确认真实的两端编辑链路已通过且旧候选可从新入口找回后，再移除旧卡片裁决、`pendingEdits` 和 MV-Register，不遗留只能由旧入口处理的数据。
- [ ] 随实现对齐全量备份说明中的合并及覆盖恢复行为。整理旧接收原型及其引用；只有确认有效内容已提取至正式文档或可从版本历史恢复，才移除过程稿。

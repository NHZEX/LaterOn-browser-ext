# WebDAV 确定性合并收藏改动并在本机找回

为让离线改动在手动同步后收敛，同时避免用户逐项裁决，首期对收藏的标题和摘要按字段用混合逻辑时钟全序合并，取代跨设备保留待裁决候选。已有收藏的自动元数据补全不产生可发布的字段修订，也不覆盖已知的手写值。字段是否手写与是否由本机用户写入是不同的事实。

编辑基线以打开编辑框时实际看到的字段来源和版本为准。提交时只保存仍有效的改动；来源已变或该字段已更新时，保持现值并在本机留存旧表单草稿。同步合并或删除传播覆盖本机手写值时，无论它是否已经发布，也在本机留存。两类记录均可在本机设置中找回，不随快照发布。新入口可用且旧候选可找回后，才移除逐字段裁决。

同 URL 只合并展示，同步状态按原始收藏 ID 独立保留成员和修订。本机关联仍属于实际存活的成员，不随规范展示 ID 转移。删除只记录发起确认时看见的原始成员 ID，压制这些 ID 的旧副本，不按 URL 删除未知成员；主动重新收藏获得新 ID。须先证明乱序和重放后成员、修订与摘要一致，再冻结快照格式。

首个隔离协议用覆盖式设备索引发布。已见较高代次的对端能拒绝倒退，首次加入端没有这份历史；实服复现了晚到旧索引使全新配置降代。新版隔离发布协议见 [ADR 0005](0005-publish-immutable-webdav-sync-records.md)，不改变本决策的合并规则。正式启用仍须通过双配置真实链路回归及逐个目标服务实测，不能证明安全的目标继续使用独立全量备份。

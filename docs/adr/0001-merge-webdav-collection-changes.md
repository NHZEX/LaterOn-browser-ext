# WebDAV 确定性合并收藏改动并在本机找回

为让离线改动在手动同步后收敛，同时避免用户逐项裁决，首期对收藏的标题和摘要按字段用混合逻辑时钟全序合并，取代跨设备保留待裁决候选。已有收藏的自动元数据补全不产生可发布的字段修订，也不覆盖已知的手写值。字段是否手写与是否由本机用户写入是不同的事实。

本机手写修订在字段改动成功提交时与正文一起落盘，未绑定或解绑期间也如此。建库和加入沿用已有修订，不把接入时间当作编辑时间。仅有手写标记的旧数据仍按原有合并和本机找回规则处理；接收他端内容不会生成本机手写修订。

编辑基线以打开编辑框时实际看到的字段来源和版本为准。提交时只保存仍有效的改动；来源已变或该字段已更新时，保持现值并在本机留存旧表单草稿。同步合并或删除传播覆盖本机手写值时，无论它是否已经发布，也在本机留存。两类记录均可在本机设置中找回，不随快照发布。新入口可用且旧候选可找回后，才移除逐字段裁决。

同 URL 只合并展示，同步状态按原始收藏 ID 独立保留成员和修订。本机关联仍属于实际存活的成员，不随规范展示 ID 转移。删除合并卡片只记录发起确认时看见的原始成员 ID。删除记录压制这些 ID 的旧副本，不按 URL 删除未知成员；主动重新收藏获得新 ID。须先证明乱序和重放后成员、修订与摘要一致，再冻结快照格式。

删除本机项目时，实际随项目删除的原始收藏 ID 与本机删除同批提交，项目及归属不随同步传播。阅读状态仍只在本机维护，因此绑定期间暂停已读自动清理，不把本机保留策略变成跨设备删除。解绑后的常规清理按原开关和保留期限执行。

首个隔离协议用覆盖式设备索引发布。已见较高代次的对端能拒绝倒退，首次加入端没有这份历史；实服复现了晚到旧索引使全新配置降代。新版发布协议及默认关闭的手动试用门槛见 [ADR 0005](0005-publish-immutable-webdav-sync-records.md)，不改变本决策的合并规则或独立全量备份。

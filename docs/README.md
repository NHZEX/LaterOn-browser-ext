## 维护约定

- `roadmap.md` 统一维护任务状态，保留 ITER 编号，通过链接引用详细方案和验证证据。
- `plans/` 按任务或相关任务组存放方案；实施后补充结果链接，阶段变更注明原因。
- `research/` 保留带日期的历史快照；新增调研注明查询日期、比较提交和验证边界，避免将历史结论当作当前实现。
- `iterations/` 按月记录实际实施与验证结果，保留提交、测试及发布证据，区分本机验证、浏览器验收和远端 CI 状态。
- `CHANGELOG.md` 记录用户可感知的版本变化，工程过程和设计依据放在相应文档，避免重复维护。

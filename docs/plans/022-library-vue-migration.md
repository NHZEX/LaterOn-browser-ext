# ITER-022：全屏收藏库渐进迁移到 Vue

更新日期：2026-10-25（Asia/Shanghai）。状态与验证记录分别见 [roadmap](../roadmap.md) 和 [实施记录](../iterations/2026-10.md)。

## 目标与边界

沿用设置页的 WXT + Vue + TypeScript，将收藏库按可独立验证的界面单元迁移，之后再迁移侧栏。保留对外 `library.html` 路径、已有样式、存储键、写入队列、归档范围和搜索语义。共享规则随页面迁移抽取，不把全量整理重复代码作为前置任务。

## 迁移顺序

| 阶段 | 实施内容 | 完成条件 | 状态 |

## A 阶段实现

- [原生页面入口](../../wxt/entrypoints/library/index.html) 由 WXT 构建；旧 HTML、控制器脚本及收藏库 CSS 退出复制清单，脚本和样式按依赖打包，访问路径保持 `library.html`。
- [App.vue](../../wxt/entrypoints/library/App.vue) 通过 Teleport 将 [LibraryHeader](../../wxt/entrypoints/library/LibraryHeader.vue) 和 [CollectionToolbar](../../wxt/entrypoints/library/CollectionToolbar.vue) 挂到原布局容器，沿用 CSS。搜索防抖及控件状态放在 [useLibraryControls](../../src/library/useLibraryControls.ts)，卸载时取消定时器和语言监听。
- [旧控制器](../../library.js) 改为模块化的 `startLibraryPage(controls)`，通过 [类型接口](../../library.d.ts) 接收控件状态和回调；不再直接维护已迁移控件的 DOM。项目、图板、收藏卡片和大部分交互仍由该控制器负责；本阶段不是整页迁移完成。
- 两页共用 [纯筛选规则](../../src/collection/filter.ts)：未读包含未读和在读，已读只包含完成；搜索去除首尾空格、忽略大小写，匹配标题、摘要、来源和网址。侧栏新增网址匹配，现有全局搜索、归档范围及清空搜索恢复行为保留。侧栏通过 [兼容入口](../../wxt/entrypoints/collection-filter.ts) 使用同一实现。
- 页面测试读取 WXT 实际构建产物；JSDOM 只重打包已编译的模块图，不另写 Vue 源码编译器。独立运行测试可按源码摘要自动构建，发布专项分别验收 production 和自定义模式的最终页面。原来调用全局内部函数的测试改为点击真实项目导航、菜单和弹窗。

## B 阶段实现

- [ProjectNavigation](../../wxt/entrypoints/library/ProjectNavigation.vue)、[ProjectRow](../../wxt/entrypoints/library/ProjectRow.vue) 和 [ProjectThumbnail](../../wxt/entrypoints/library/ProjectThumbnail.vue) 接管项目导航、计数、置顶标识、缩略图及就地重命名；活动项目和输入草稿统一由 `useLibraryControls` 管理。键控项目行在外部更新时保留输入框、焦点和光标，Enter / 失焦提交，Escape 取消，F2 继续可用。
- [ProjectBoards](../../wxt/entrypoints/library/ProjectBoards.vue)、[ProjectBoard](../../wxt/entrypoints/library/ProjectBoard.vue) 和 [BoardImage](../../wxt/entrypoints/library/BoardImage.vue) 接管图板、组合封面、图片降级及新建入口；空态交给 `App.vue`。删除旧图板模板、命令式项目列表和图板构建代码。默认占位图复用经典页面所需的公共资源，避免重复打包。
- [项目纯规则](../../src/library/shared.ts) 负责导航投影、归档 / 阅读筛选、封面选择、简介与统计。图板封面和底部统计继续描述整个项目，不因阅读筛选改变；空项目保留图板，归档项目继续可见。控制器以只读集合快照更新 Vue，操作仍通过带类型回调和现有写入队列执行。
- 项目菜单、编辑弹窗、拖拽算法和侧栏宽度行为暂留控制器，节点创建和点击事件由 Vue 接管。拖拽监听委托到稳定容器；更新集合前清理临时拖影、指示线和变换，动画帧检查拖拽是否仍有效，防止外部同步后留下残影或提交过期顺序。侧栏落点按可见项目计算，隐藏的归档置顶项目不再干扰排序。
- 新增不可变输入的项目规则回归；production 和自定义模式的实际构建页面均覆盖无自身广播更新、外部同步、重命名失败 / 重试、焦点与光标、图片回退、置顶分隔线、归档恢复、拖拽取消与隐藏项目排序。封面降级测试执行真实模块及两页图片错误事件；删除对应的业务源码匹配断言，保留其他存量改进范围。
- 下一批为 C：迁移收藏列表与卡片展示，复用已有阅读状态和封面规则，保留首屏及分批渲染、当前阅读位置、搜索与筛选。菜单、弹窗、拖拽和批量操作在 D 阶段继续迁移，最后移除旧控制器；不把 B 阶段视为收藏库整页迁移完成。

## C 阶段实现

- [CollectionCards](../../wxt/entrypoints/library/CollectionCards.vue)、[CollectionCard](../../wxt/entrypoints/library/CollectionCard.vue) 和 [CardCover](../../wxt/entrypoints/library/CardCover.vue) 接管列表与卡片节点，移除静态卡片模板和旧控制器的卡片创建、内容更新、选择样式及图片错误处理。安全链接、阅读状态、封面解析、YouTube 降级和公共占位图沿用共享规则。
- [列表投影](../../src/library/shared.ts) 统一归档范围、跨项目搜索、阅读筛选和各范围自定义顺序；输入保持只读。选择集合与当前阅读标识由控制器传入 Vue，稳定网格容器继续委托菜单、弹窗、项目选择、拖拽和批量操作，不重复注册卡片事件。
- [useBatchedCards](../../src/library/useBatchedCards.ts) 首批显示 48 条，其余排入可取消的空闲批次；切换范围或筛选后，过期任务不能重新插入卡片。键控卡片保留仍可见节点、焦点和封面回退状态；批次提交后才定位当前阅读目标。外部集合同步前取消拖拽，清除临时节点和变换。
- [页面行为回归](../../tests/library-cards.test.js) 执行真实编译页面与存储协调器，覆盖千条分批及取消、后批定位、写入失败 / 重试、无自身广播更新、创建项目并移动、焦点与图片状态。既有编辑、删除、搜索及批量回归同样执行 Vue 页面；删除卡片 CSS 源码正则，实际布局与原生鼠标拖拽由 [Chromium 扩展检查](../../tests/browser/library.spec.cjs) 接替。
- 下一批 D 逐项迁移菜单、弹窗、拖拽和批量操作，替换对应控制器代码，最后移除旧控制器。C 不代表整页交互迁移完成。

## D1：项目与收藏菜单

- [LibraryMenu](../../wxt/entrypoints/library/LibraryMenu.vue) 统一管理项目菜单与收藏卡片右键菜单，并通过 Teleport 挂到 body；[菜单模型](../../src/library/menu.ts) 从当前只读集合、选择状态和语言派生标题及操作。保留现有图标与样式，删除旧控制器中的菜单 DOM 创建、定位、图标和关闭监听；Vue 卸载时清除监听与动画帧。
- 支持首项聚焦、上下循环、Home / End、Enter / Space 原生按钮激活、Escape 关闭及 Tab / Shift+Tab 离开。项目更多按钮、项目导航和图板支持键盘菜单，卡片内部可聚焦控件支持 ContextMenu / Shift+F10；关闭菜单和执行操作时恢复触发器焦点，再交给重命名或弹窗管理焦点。点击外部、滚动、resize 和窗口失焦关闭菜单；不把焦点抢回菜单。
- 外部改名、置顶、归档、收藏内容和语言变化实时更新菜单；外部删除目标后关闭并回到仍可用的焦点。操作按 ID 重新读取最新记录，继续使用既有后台写入队列；统一捕获操作失败，允许重新打开重试。菜单内 pointerdown 不退出多选，Escape 优先关闭菜单而不退出选择会话。
- [新增页面回归](../../tests/library-menus.test.js) 覆盖上述状态、焦点、关闭、失败重试和过期帧；production / 自定义构建验证实际编译菜单的键盘与焦点行为。Chromium 增加深浅主题、中英文的原生键盘、弹窗焦点移交、窄屏定位、滚动和外部同步场景；删除旧菜单样式源码正则。详细验证与包体变化见实施记录。
- 本批仅迁移菜单显示与生命周期。后续依次迁移批量工具栏、弹窗与拖拽，最终移除控制器；不将 D1 视为 D 全部完成。

## D2：选择状态与批量操作

- [useLibrarySelection](../../src/library/useLibrarySelection.ts) 成为选择状态唯一所有者；旧控制器不再保存模式和选择集合，也不再同步计数 / 选中样式。筛选、搜索和卡片项目切换保留仍存在的已选项；外部删除清理失效 ID，进入图板或退出选择清空会话。
- [BulkToolbar](../../wxt/entrypoints/library/BulkToolbar.vue) 管理批量栏 DOM、动态文案、空选择和操作中状态、键盘退出及外部点击监听；卸载时移除监听。操作开始时将栏内焦点交给仍可用的“完成”按钮，避免禁用按钮使焦点丢失，退出时返回可见入口。[CollectionCards](../../wxt/entrypoints/library/CollectionCards.vue) 接管网格容器，卡片选择事件由 Vue 处理；复选框保留原生 Space / change 行为，标题与封面选择时阻止跳转。
- [useLibraryBulk](../../src/library/useLibraryBulk.ts) 管理标完成 / 未读、移动、删除与新窗口打开流程。旧控制器仅注入共享存储提交、确认框、项目选择器及窗口 API 适配；不再保留批量业务函数。失败保留选择，移动失败留在原浮层重试；提交中拒绝重复操作。确认框与移动浮层固定目标，成功仅移除本次覆盖的选择；同一会话新选的条目和新会话不会被旧回调清空。退出或卸载关闭移动浮层，失效浮层也不能新建项目。
- 全选基于完整有序结果，不依赖首批 48 张 DOM；取消全选仅撤销当前结果，保留隐藏选择。所有批量命令覆盖全部已选项；新窗口先按当前结果顺序打开，再补筛选隐藏的已选项，并过滤危险网址，修正原先只打开已渲染可见卡片的遗漏。
- [12 个页面场景](../../tests/library-bulk.test.js) 使用真实编译 Vue 页面和存储协调器，自身广播关闭；控制外部广播、写失败、存储挂起和窗口 API。多选时阻止卡片原生项目变更并恢复显示值，退出后允许正常移动。production / 自定义构建补批量操作结果验证；Chromium 增加深浅主题、中英文的原生键盘、移动、删除及重载持久化、窄屏布局场景，并检查项目下拉框的原生键盘操作不会绕过多选保护。

## D3：项目与收藏编辑及命令

- [useLibraryProjects](../../src/library/useLibraryProjects.ts) 管理新建、就地改名、项目简介 / 自定义封面 / 组合封面编辑、置顶、归档恢复及删除；[useLibraryItems](../../src/library/useLibraryItems.ts) 管理单篇编辑、阅读标记、移动与删除。对应业务函数及卡片事件委托从旧控制器删除，卡片操作由 Vue 直接调用，菜单按目标 ID 派发。继续复用两页共享的 `dialog.js`、`picker-ui.js` 与封面处理能力，不重复实现弹窗。
- [useLibraryCommands](../../src/library/useLibraryCommands.ts) 提供带类型的存储 / 弹窗 / 选择器边界、成功响应处理入口、错误提示和按目标防重入；卸载关闭自己的弹窗并使迟到响应失效。单篇移动失败保留原浮层重试，失效浮层不能再写入；就地改名失败保留草稿并重新聚焦。旧控制器只注入共享队列、界面和页面适配，不再编排编辑业务。
- 编辑比较打开时快照，仅提交实际改动字段，保留外部更新的其它字段；项目自动封面不固化，组合封面按用户顺序保存。外部删除目标后不发陈旧命令。弹窗保存 / 取消后恢复仍存在且可见的入口，删除入口消失时回到搜索框；键控输入框在外部更新时保留草稿、焦点和光标。

- 本批 `library.js` 从 1,520 行缩至 1,124 行；补齐迁移注释后三个新职责模块分别为 110 / 103 / 71 行。具体测试和包体记录见实施记录；随本次提交，未推送、未发布至实际安装目录。

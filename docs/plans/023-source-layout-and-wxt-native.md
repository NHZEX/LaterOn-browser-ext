## F3b 国际化、弹窗与引导模块化

国际化词典与运行时显式导出 `t`、`ready`、语言读取 / 写入及静态壳翻译；TypeScript 入口复用同一状态，设置页继续保存后重载。收藏库等待首轮语言读取，侧栏继续并行读取并先画缓存；跨页设置通知更新语言，迟到的初始读取不能覆盖更新，卸载移除订阅。Vue 文案由响应式绑定更新，保留静态页面壳翻译。

弹窗通过 `dialog` 模块服务保留确认、输入、封面上传 / 移除、拼图、键盘和顺序排队；公共输入 / 结果类型集中至 `src/ui/types.ts`。两页统一原生动态导入，侧栏样式继续按需加载并支持样式失败后重试，收藏库复用原生 HTML 导入的样式。先前静态 / 动态混合导入的产物会把设置页入口带入编辑器依赖链，统一动态导入后消除这一副作用；新增浏览器场景核对请求及实际页面。普通 `close` 保留逐个关闭语义，页级 `dispose` 取消当前与排队请求，迟到上传不再改写下一弹窗；存储桥只负责传输，提示由原生页面注册并在卸载时清理。

引导提供显式 `initOnboarding` / `openOnboarding` / 清理函数，由两页 Vue 生命周期拥有。保留已读判断、语言就绪后的 220ms 延迟、`guide=1` 重播和三步内容；移除自动 DOMContentLoaded 启动及 `LaterOnOnboarding`。销毁清理读取后续任务、打开 / 过渡 / 关闭计时器、帧与监听，不写已读；完成 / 跳过才持久化并恢复焦点。收藏库在语言返回前卸载也不会迟到挂载。

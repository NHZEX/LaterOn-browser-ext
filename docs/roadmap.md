## 测试改进的迭代方式（ITER-021）

按相关功能变更、缺陷修复和 CI 误报逐步推进，每轮限定可审查范围；新增和修改的测试遵守 [测试约定](../AGENTS.md#测试约定)，存量问题不要求立即全量重写，也不作为无关功能迭代的统一前置条件。

- **已完成：编辑流程。** `784e962` 移除源码匹配断言，收藏库与侧边栏共用真实编辑行为回归，覆盖无存储广播更新、取消、无改动保存、写入失败与重试。本地完整测试 64/64 通过，CRLF 输入验证通过；远端 Windows / Ubuntu CI 待复验。
- **本轮增补：共享编辑规则。** 随 ITER-009 A 增加纯模块与经典脚本入口测试，两页真实编辑回归补足本地封面预览、只改文字保留封面、移除封面及其他图片保留；发布专项执行实际编译产物。完整测试 65/65 通过，远端 CI 待复验。
- **本轮增补：状态与迁移。** 随 ITER-009 B 执行共享状态模块、真实后台迁移 / 清理及两页完整入口，覆盖失败后重开、计时稳定、手动状态更新、外部广播和侧栏缓存。`cover-save-failure.test.js` 的迁移源码切片已移至完整页面回归，其余修改处理函数的切片留待相关迭代。完整测试 67/67 通过，远端 CI 待复验。
- **本轮增补：Vue 收藏库。** 随 ITER-022 A 将收藏库 DOM 回归切到 WXT 实际编译页面，替换项目、图板封面等测试中对旧全局内部函数的调用；新增共享筛选规则、网址搜索和真实产物控件验证。正式扩展加载和远端 CI 待验收。
- **本轮增补：Vue 项目导航与图板。** 随 ITER-022 B 新增项目纯模块回归和两种构建模式的实际页面验证，覆盖无自身广播更新、重命名失败 / 重试及焦点保持、封面降级、归档恢复、拖拽与外部更新。封面降级不再切片函数或匹配业务源码；两页图片错误处理通过实际事件验证。完整测试 69/69 通过，正式扩展加载和远端 CI 待验收。
- **后续优先：侧边栏交互与生命周期。** 涉及链接、修饰键、右键菜单或扩展启动行为时，将 `sidepanel-link-actions.test.js`、`action-sidepanel.test.js` 中的功能源码断言改为实际事件及浏览器 API 结果验证，保留明确的结构化配置契约。
- **后续优先：数据修改流程。** 涉及删除、封面和关联数据时，改进 `sidepanel-delete.test.js`、`cover-save-failure.test.js` 等回归，执行真实存储逻辑，验证目标条目、其他数据保留、取消、写入失败及恢复重试。
- **随重复需求整理基础设施。** 复用浏览器 API、存储故障与广播控制夹具，用有超时的条件等待替换固定延时；已有行为验证但依赖源码切片的测试，随模块迁移逐步转为完整模块调用。

每批记录已改造文件、保障的行为、验证结果和剩余事项。功能出现真实退化应使测试失败，等价重构、注释、排版及换行变化不应触发功能断言失败。
